# Neural Network Quantum States — Variational Monte Carlo

A machine learning approach to solving quantum mechanics problems,
applied to the anharmonic oscillator. Built as a graduation project
at King Saud University (ranked 1st in cohort, 4.95/5.0 GPA).

**🏆 Won 1st place in the KSU Physics Graduation Project competition.**

## What This Project Does

Computing the energy of quantum systems is a hard problem — the
complexity grows exponentially with system size using traditional
methods. This project uses a neural network as a flexible mathematical
function to estimate ground-state energies, combined with a Monte Carlo
sampling algorithm to optimize it.

The result: stable, accurate energy estimates at complexity levels
where standard methods break down.

## Technical Approach

- **Model:** Neural network as a variational wave function (PyTorch)
- **Sampling:** Metropolis–Hastings Monte Carlo
- **Optimization:** Stochastic Reconfiguration (natural gradient descent)
- **System:** Anharmonic oscillator (quantum mechanics benchmark problem)

## Key Result

Demonstrated significantly improved scalability over baseline methods,
producing stable energy estimates at substantially higher complexity —
where traditional approaches become computationally infeasible.
